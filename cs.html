Interactive CS and AI Demos

Browser simulations that make algorithms and machine learning visible. Every demo starts with a system that knows nothing, lets the learner break or train it, and shows the numbers behind each decision.

Algorithms

Graphs · Dijkstra's algorithm

Route Lab: How a GPS Uses Live Data

Simulated phones report speeds on a military base. Crash or close a road, then watch Dijkstra's algorithm search, finalize intersections by cost, and reroute the car once the evidence arrives.

Learners see how weights drive a shortest path, and why a system acts on beliefs, not truth.

Reinforcement learning

Q-learning · Self-play · Bandits

Four Agents That Teach Themselves

Grid World, Self-Play Tic-Tac-Toe, Slot Machines, and Deep Scan. Each agent starts untrained. Learners tune the learning rate and exploration, train, and watch the reward curve climb.

Learners see a policy form from one number of feedback.

How models work

Language models · Sampling

How an LLM Generates Text

A real GPT-2 model runs in the browser. Learners pick each next token, change the temperature, and see the probabilities behind every word.

Learners see that a language model predicts, one token at a time.

Downloads the model on first load, so give it a minute.

 Transformers · Matrices

Opening the Black Box

Step through the matrix math inside an LLM, from a prompt to its predicted next word.

Learners see that a model's "thinking" is linear algebra. Embeddings · Vector spaces

3D Word Embedding Space

Rotate a 3D space where words with similar meanings cluster together.

Learners see meaning as distance between vectors. Neural networks · Classification

Train a Model on Your Own Field

Train a small neural network in the browser on data from cybersecurity, healthcare, logistics, equipment maintenance, or streaming, or upload your own CSV. Then test predictions and their confidence.

Learners see training, testing, and confidence on data they recognize. Computer vision · Pixels

How Computer Vision Sees

Zoom into a photo pixel by pixel, see the RGB numbers behind each square, and follow edge detection and the stages of vision.

Learners see that an image is a grid of numbers.
