## Design approach

Learners commit to a decision before the simulation reveals the outcome. The search-and-rescue sim hides the ejection point until the learner has computed the diagonal and committed a center. The balloon sim asks learners to write the equation before the launch tests it.

Built with HTML, CSS, and JavaScript (Canvas 2D). Designed by Cynthia L. McGinnis.
