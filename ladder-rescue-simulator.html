Mathematical Foundations

Everything the Ladder Simulator uses comes from two core College Algebra concepts — the Pythagorean Theorem and basic trigonometry.

Pythagorean Theorem

For any right triangle with legs a and b and hypotenuse c:

a² + b² = c²

For a ladder:
height² + base² = length²

Solving for length:
c = √(a² + b²)

The ladder is always the hypotenuse — the longest side.

Safe Angle Calculation

The climb angle θ is measured from the ground to the ladder:

tan(θ) = height / base
θ = arctan(h / d)

Safe range: 70° ≤ θ ≤ 80°
Optimal: θ ≈ 75–76°

OSHA recommends 75°. The 4:1 rule achieves ~76°.

The 4:1 Safety Rule

  • Set the base 1 ft out for every 4 ft of height.
  • Example: 20 ft wall → base at 5 ft from wall.
  • Gives arctan(4) ≈ 76° — within the safe zone.
  • Too flat (<70°): ladder slides outward.
  • Too steep (>80°): ladder tips backward.

Common Mistakes

  • Forgetting to square root: c = √(a²+b²), not a²+b².
  • Wrong hypotenuse: the ladder (longest side) is always c.
  • Inverting arctan: it's h/d, not d/h.
  • Mixed units: height and base must be in the same unit.
